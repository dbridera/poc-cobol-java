add-policy-facade — COBOL ↔ Java

  1. Del Java al COBOL: en el panel derecho, clic en un COBOL: archivo:líneas. El panel izquierdo salta y pinta de amarillo esas líneas. El Java no se mueve: la línea que tocaste queda marcada en azul.
  2. Del COBOL al Java: en el panel izquierdo, clic en una fila azul (un párrafo). El panel derecho salta solo al Java que lo traduce y lo marca en azul. Si lo traducen varios lugares, la barra del medio los lista: clic en otro para verlo.
  3. Qué hace cada parte: cada programa empieza con un resumen de negocio y cada párrafo lleva debajo una línea "Qué hace" con la sección de la especificación (viene de PARAGRAPHS.md). Al hacer clic en una cita del Java, la barra del medio también explica el párrafo citado.
  4. Etiquetas de cada párrafo: 6/6 fixtures en cuántos casos de prueba se ejecutó · 2 Java citations cuántas veces lo cita el Java · not cited by Java ningún Java lo cita · 0/6 fixtures ningún caso lo ejecuta.
